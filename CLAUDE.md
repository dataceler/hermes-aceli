# Claude Code — contexto do repositório

Este é um repositório privado de operação e backup sanitizado da Aceli/Dataceler.

- Leia `AGENTS.md` e `docs/security-and-sync.md` antes de editar.
- Nunca leia, solicite ou escreva credenciais para este repositório.
- Nunca execute `git push`, alterações de permissões GitHub ou mudanças em infraestrutura sem autorização explícita.
- Para mudanças de estrutura, atualize `MAPA.md`, documentação e validação junto.
- Execute `python3 scripts/verify_sanitized_export.py` antes de propor um commit.
