# MEMORY — índice de memória durável

A memória versionada vive em `runtime/memories/`, exportada de forma sanitizada. Esta página é o índice humano.

- `runtime/memories/MEMORY.md`: fatos operacionais duráveis.
- `runtime/memories/USER.md`: preferências de trabalho autorizadas.
- `memory/context/`: contexto de trabalho explicitamente registrado para decisões atuais.
- `memory/projects/`: estado de cada projeto.
- `memory/daily/`: diário operacional, sujeito a retenção e poda.

Não use este repositório para guardar conversa bruta, dados pessoais excessivos ou material que não precise sobreviver ao runtime.
