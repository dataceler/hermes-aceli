# Registro dos templates Canva

Use este arquivo para registrar somente templates confirmados pelo usuário. Não adivinhe IDs e não registre candidatos não aprovados.

## João Cordeiro

- Brand Template ID: não identificado
- Design ID alternativo: não identificado
- Nome confirmado: não identificado
- Data da confirmação: não identificada

## Dataceler

- Brand Template ID: não identificado
- Design ID alternativo: não identificado
- Nome confirmado: não identificado
- Data da confirmação: não identificada

## Regras

- Pesquisar brand templates primeiro.
- Registrar apenas após confirmação inequívoca por nome/miniatura ou ID fornecido.
- Duplicar o template em cada nova produção.
- Nunca editar o ID registrado como original.
