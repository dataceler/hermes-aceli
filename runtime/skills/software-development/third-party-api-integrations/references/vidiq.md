# vidIQ MCP

## Official service

- Server: `https://mcp.vidiq.com/mcp`
- Official docs: `https://support.vidiq.com/en/articles/15082430-vidiq-mcp`
- Transport: remote HTTPS MCP
- Auth: OAuth 2.1 with PKCE, or an MCP-scoped API key generated by vidIQ
- Channel access: read-only. The only documented account mutation is the vidIQ competitor watchlist.

## Hermes setup

Prefer OAuth so credentials never enter chat or shell history:

```bash
hermes mcp add vidiq \
  --url https://mcp.vidiq.com/mcp \
  --auth oauth \
  --connect-timeout 300
```

On a headless host, open the displayed authorization URL on the user's computer. After consent, the browser redirects to a loopback URL that may fail to load. Paste the complete callback URL into the tracked CLI process. The authorization code is one-time and must not be logged or retained.

## Least-privilege selection

Do not accept all tools automatically. The server currently exposes tools for analytics plus media generation, voice cloning, video editing and competitor-watchlist mutation.

A safe default keeps analytics/research tools and disables:

- deprecated tools;
- `vidiq_submit_feedback`;
- `vidiq_update_competitors`;
- thumbnail generation/refinement;
- voice, music, video, motion-graphics, clips and media-editing tools;
- generation-job utilities when generation tools are disabled.

Title scoring/generation and `vidiq_video_watch` may remain enabled, but note that they consume credits. Most paid calls cost 5 credits; video/reel watch calls commonly cost 10. Balance, connected channels and some utility calls are free.

## Verification

```bash
hermes mcp test vidiq
hermes mcp list
```

Then start a fresh Hermes process and call only:

- `vidiq_balance`
- `vidiq_user_channels`

Confirm authentication, channel count and credit balance without printing private analytics or tokens. OAuth credential files must have POSIX mode `600`.

MCP tools load at process startup. Restart the gateway or start a fresh session before expecting the new tools in Telegram/Discord.

## Documentation discrepancy

The official support article may state launch-period availability on all plans, while the marketing page may state Max-only access. Treat actual OAuth/tool-call success and the account's returned balance as authoritative for the connected account.
